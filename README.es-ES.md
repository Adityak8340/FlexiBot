# FlexiBot 🤖

¡Bienvenido a FlexiBot, tu chatbot receptivo y amigable! FlexiBot puede ayudarte con preguntas, brindar información o simplemente charlar por diversión. Además, FlexiBot puede analizar imágenes. ¡Comencemos nuestra conversación!

## Cómo usarlo

1. **Haz una pregunta o proporciona una entrada para el análisis de imágenes**: Escribe tu pregunta en el cuadro de texto proporcionado o carga una imagen.
2. **Personalización**: Puedes personalizar la experiencia de chat ajustando los mensajes del sistema, eligiendo diferentes modelos y configurando la longitud de la memoria conversacional.
3. **Velocidad de escritura**: Ajusta el control deslizante de velocidad de escritura para controlar lo rápido que responde FlexiBot.

## Personalización

FlexiBot ofrece varias opciones de personalización:

- **Mensaje del sistema**: Personaliza el mensaje inicial que proporciona FlexiBot.
- **Modelo**: Elige entre diferentes modelos de lenguaje para impulsar las respuestas de FlexiBot.
- **Longitud de la memoria conversacional**: Ajusta la longitud de la memoria de FlexiBot para una mejor retención del contexto.
- **Velocidad de escritura**: Controla lo rápido que FlexiBot escribe sus respuestas.

## Características

- **Interfaz receptiva**: Disfruta de una experiencia de chat fluida con la interfaz adaptable de FlexiBot.
- **Análisis de imágenes**: Carga una imagen y obtén una respuesta basada en el análisis.
- **Efecto de escritura realista**: FlexiBot escribe las respuestas de manera realista para una interacción atractiva.
- **Retención de contexto**: FlexiBot recuerda conversaciones anteriores para mantener el contexto durante todo el chat.
- **Múltiples modelos de lenguaje**: Elige entre una variedad de modelos de lenguaje para adaptarse a tus necesidades de conversación.

## Tecnologías utilizadas

- **Streamlit**: El framework de interfaz de usuario utilizado para construir la interfaz del chatbot.
- **Groq**: Potencia las capacidades de comprensión del lenguaje de FlexiBot.
- **Langchain**: Proporciona funciones de memoria conversacional y gestión de contexto.
- **dotenv**: Permite cargar variables de entorno desde un archivo `.env`.
- **Google Generative AI**: Se utiliza para generar contenido y analizar imágenes.
- **PIL**: Se utiliza para el procesamiento de imágenes.

## Cómo empezar

Para ejecutar FlexiBot localmente, sigue estos pasos:

1. Clona este repositorio.
2. Instala las dependencias requeridas ejecutando `pip install -r requirements.txt`.
3. Crea un archivo `.env` y configura tu `GROQ_API_KEY` y `GOOGLE_API_KEY`.
4. Ejecuta la aplicación de Streamlit usando `streamlit run app.py`.
